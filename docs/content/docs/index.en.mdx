## What is this service?

<b>FragAPI</b> - API Service, with 100% [open source
code](https://github.com/apelsynca/fragapi), с помощью которого можно:

Пользоваться функционалом fragapi в виде API

### What can it do?

Why use it, over usual fragment?:

- Provides automation of fragment.
- No KYC required.
- No need in 24 words or interaction with wallet at all.
- Notifications about your fragment transactions

### Коммисия

Service takes commision for each transaction.

<b>0.5%</b> + ~0.0001 GRAM (network fee, +-$0.0001)
