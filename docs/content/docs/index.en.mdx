## What is this service?

<b>FragAPI</b> - API Service, with 100% [open source
code](https://github.com/apelsynca/fragapi)

That allows you to use https://fragment.com (TON) functionale.

### What can it do?

Why use it, over just fragment?:

- Provides automation of fragment.
- No KYC required.
- No need in 24 words or code interaction with ton wallet at all.
- Can setup in 2 clicks notifications about your fragment transactions

### Commision

Service takes commision for each transaction.

<b>0.5%</b> + ~0.0001 GRAM (network fee, +-$0.0001)

<Callout title="Commision will change!" type="warn">
  Commission top-up planned from <b>0.5%</b> to <b>2.5%</b> beginning at
  25.06.2026 (UTC).

Network fee would be removed.

</Callout>
