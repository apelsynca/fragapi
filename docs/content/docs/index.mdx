## Что это за сервис?

<b>FragAPI</b> - API Сервис, с на 100% [открытым исходным
кодом](https://github.com/apelsynca/fragapi), с помощью которого можно:

Пользоваться функционалом fragapi в виде API

##### Что он может?

Зачем его юзать, вместо обычного фрагмента:

- Дает полную автоматизацию покупок звезд, премиума
- Не нужно KYC.
- Не нужно 24 слова.
- Настраиваются уведомления о покупках
- Не нужно с нуля писать свою автоматизацию fragment

### Коммисия

Сервис берет коммисию за каждую успешную транзакцию. <b>~2%</b> (1.8% + коммисия сети +-0.001 GRAM)

## Какой функционал доступен?

- [x] Покупка звезд
- [x] Покупка premium
- [x] Просмотр hash транзакций в TON
- [x] Возможность настроить уведомления в телеграмм о транзакциях в выбранный чат
- [x] Статистика покупок/транзакций
- [x] Пополнения через API сервиса (отвечает payload или memo)
- [x] Панель в которой можно видеть статистику о транзакциях/депозитах
- [ ] Информация/статистика о коллекциях подарков
- [ ] Покупка GRAM на аккаунт телеграмм
