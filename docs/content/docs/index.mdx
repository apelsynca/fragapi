## Что это за сервис?

<b>FragAPI</b> - API Сервис, с на 100% [открытым исходным
кодом](https://github.com/apelsynca/fragapi), с помощью которого можно:

Пользоваться функционалом fragapi в виде API

##### Что он может?

Зачем его юзать, вместо обычного фрагмента:

- Дает автоматизацию покупок звезд, премиума
- Не нужно KYC.
- Не нужно 24 слова.
- Настраиваются уведомления о покупках
- Не нужно с нуля писать свою автоматизацию fragment

### Коммисия

Сервис берет коммисию за каждую успешную транзакцию.

<b>0.5%</b> + ~0.0001 GRAM (коммисия сети тон)

<Callout title="Коммисия изменится!" type="warn">
Планируется смена коммисии с <b>0.5% + коммисия сети</b> на систему тиров

- <b>Уровень 1:</b> 2.5% 0$-500$ / месяц
- <b>Уровень 2:</b> 2.0% 500$-1500$ / месяц
- <b>Уровень 3:</b> 1.0% 1500$+ / месяц
</Callout>
